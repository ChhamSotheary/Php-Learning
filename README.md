# វគ្គសិក្សា PHP ជាភាសាខ្មែរ

វគ្គសិក្សានេះរៀបចំតាមលំដាប់ពី Beginner ទៅ Advanced ហើយបន្តទៅ Laravel, Symfony និង Portfolio Projects។

## ផែនទីសិក្សា (Roadmap)

1. **PHP Fundamentals** — មូលដ្ឋាន PHP
2. **Web Development** — PHP ជាមួយ HTML, Forms, Requests និង Sessions
3. **MySQL / PDO** — Database និងការភ្ជាប់ PHP
4. **Object-Oriented Programming (OOP)** — Classes, Objects, Inheritance និងចំណុចពាក់ព័ន្ធ
5. **Composer / PSR / Testing / API** — ការគ្រប់គ្រង Dependencies, Coding Standards, Tests និង API
6. **Security / Advanced PHP** — សុវត្ថិភាព និងមុខវិជ្ជាកម្រិតខ្ពស់
7. **Laravel** — Laravel Framework
8. **Symfony** — Symfony Framework
9. **Portfolio Projects** — គម្រោងអនុវត្តសម្រាប់ Portfolio

## របៀបរៀន

- រៀនតាមលេខមេរៀន ដោយមិនរំលងមូលដ្ឋាន។
- មេរៀននីមួយៗមានគោលបំណង ទ្រឹស្តី ពាក្យបច្ចេកទេស កូដអនុវត្ត ការពន្យល់ លទ្ធផលរំពឹងទុក កំហុសទូទៅ លំហាត់ និងសំណួរត្រួតពិនិត្យ។
- ចម្លើយលំហាត់ដាក់នៅផ្នែកដាច់ដោយឡែក ដើម្បីឱ្យអ្នករៀនអាចសាកល្បងមុន។
- ពិនិត្យឯកសារយោងផ្លូវការរបស់ PHP និង Frameworks នៅពេលព័ត៌មានអាចផ្លាស់ប្តូរ។
- មេរៀនថ្មីត្រូវបន្តពីមេរៀនមុន និងមានសេចក្ដីណែនាំសម្រាប់សាកល្បងលើកុំព្យូទ័រ។

## តម្រូវការដំបូង

- កុំព្យូទ័រ Windows, Linux ឬ macOS
- Visual Studio Code ឬ Text Editor ផ្សេង
- PHP CLI ដែលមាន Version នៅក្នុងបញ្ជី Supported Versions របស់ PHP
- Web Browser
- Terminal / Command Prompt

សូមពិនិត្យ Version ដោយប្រើ៖

```bash
php -v
```

ការដំឡើង៖ [PHP Installation Manual](https://www.php.net/manual/en/install.php)
